# JenPay – E-Wallet

A front-end e-wallet demo: send, receive and buy. Plain HTML, CSS and JavaScript – no build step.

## Run
Open `index.html` in a browser.

## Structure
| File | Purpose |
| --- | --- |
| `index.html` | Page shell |
| `style.css` | Theme tokens (light/dark) and components |
| `app.js` | State, screens, navigation and actions |
| `assets/logo.png` | JenPay logo |

## Notes
- Data is stored in memory only and resets on reload.
- Any 4-digit PIN is accepted (demo).
